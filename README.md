# IMDB Movies Analysis - Power BI Dashboard
[View Dashboard](https://app.powerbi.com/groups/me/reports/35bad832-e153-44f2-91ca-a5389f51c552/a793471958ed7b2e078c?experience=power-bi)

## 📊 Project Overview

This project presents a comprehensive analysis of IMDB movie data using Power BI. The dashboard provides interactive visualizations and insights into movie trends, ratings, genres, and performance metrics across different time periods.

## 🎯 Objectives

- Analyze movie ratings and their distribution across different genres
- Identify trends in movie production over the years
- Explore relationships between budget, revenue, and ratings
- Provide insights into top-performing movies and directors
- Enable data-driven decision making for stakeholders in the film industry

## 📁 Dataset Information

The analysis is based on IMDB movie dataset containing information about:
- Movie titles and release years
- IMDB ratings and vote counts
- Genres and classifications
- Budget and revenue figures
- Directors and cast information
- Runtime and other metadata

## 🔍 Key Features

### Dashboard Components

1. **Rating Analysis**: Distribution of IMDB ratings across movies
2. **Genre Performance**: Breakdown of movies by genre with performance metrics
3. **Temporal Trends**: Year-over-year analysis of movie production and ratings
4. **Financial Insights**: Budget vs revenue analysis with ROI calculations
5. **Top Performers**: Highlighting highest-rated movies and most successful directors

### Interactive Elements

- Dynamic filters for year, genre, and rating ranges
- Drill-down capabilities for detailed analysis
- Cross-filtering across visualizations
- Custom tooltips with additional information

## 🛠️ Tools & Technologies

- **Power BI Desktop**: For creating interactive dashboards and visualizations
- **Power Query**: For data transformation and cleaning
- **DAX (Data Analysis Expressions)**: For calculated measures and columns

## 📈 Key Insights

The dashboard reveals insights such as:
- Evolution of movie ratings over decades
- Most popular and highest-rated genres
- Correlation between budget and box office success
- Seasonal trends in movie releases
- Director and studio performance comparisons

## 🚀 Getting Started

### Prerequisites

- Power BI Desktop (latest version recommended)
- Basic understanding of Power BI interface

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/nil-adhav/IMDB-MOVIES-ANALYSIS-POWER-BI.git
   ```

2. Navigate to the project directory:
   ```bash
   cd IMDB-MOVIES-ANALYSIS-POWER-BI
   ```

3. Open the `.pbix` file with Power BI Desktop

4. Refresh the data if needed to see the latest updates

## 📊 Usage

1. Open the Power BI dashboard file
2. Use the filters and slicers to customize your view
3. Click on visual elements to cross-filter data
4. Hover over data points for detailed tooltips
5. Export visualizations or reports as needed
